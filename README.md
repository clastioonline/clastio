# AI Teacher Assistant

A personal AI teaching assistant for teachers, starting in the UAE with India and international markets to follow. It learns a teacher's slide design, teaching style and curriculum progress. From that it produces connected lessons, editable PPTX in the teacher's own design, notes, worksheets, quizzes and homework, and it delivers daily plans through WhatsApp.
